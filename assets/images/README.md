# MRecipes image assets

Store optimized, properly licensed site and recipe images in this directory.

- Use descriptive, lowercase, hyphen-separated filenames (for example, `creamy-garlic-parmesan-chicken.webp`).
- Prefer WebP or AVIF for photographs and provide meaningful `alt` text in HTML.
- Keep image URLs and references consistent with the canonical `https://mrecipes.online/` domain.
- Do not publish images unless you own them or have a license that permits website use.
- Before adding a recipe image, update the recipe page and its `Recipe` JSON-LD `image` field to use the same real image URL.
- Do not use placeholder images or invent image URLs in structured data.
